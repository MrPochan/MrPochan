# Оборона острова

Браузерная tower defense в пиксель-арте, вдохновлённая War Front: вид сверху, остров с нефтебазой, враг атакует с моря и с воздуха.

Запуск: открыть `index.html` в браузере (без сборки и зависимостей). Работает на телефоне и десктопе.

## Враги
- **Десантный катер** — подплывает к берегу и высаживает пехоту (топи катер до высадки).
- **Танковый десант** — катер с двумя танками и пехотой (с волны 6).
- **Транспортник** — пролетает над островом и сбрасывает парашютистов (с волны 3).
- **Бомбардировщик** — заходит на здание и бомбит по линии (с волны 4).

## Оборона
| Постройка | Цель | Заметки |
|---|---|---|
| Пулемёт | земля, катера | скорострельный, ближний |
| Пушка | земля, катера | снаряд с уроном по площади |
| Зенитка | самолёты, парашюты | быстрая, неточная |
| ЗРК | самолёты | самонаводящиеся ракеты, дальний |
| Качалка | — | даёт нефть |

Тап по постройке: улучшить (до 3 ур.), починить, продать. Горячие клавиши: `1–5` выбор, `Esc` отмена, `Пробел` пауза. На сенсоре первый тап ставит призрак, второй по нему — строит.

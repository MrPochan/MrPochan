# @cupquest/client

Браузерный клиент «Кубкового квеста»: Phaser 3 для арены боя и поля шаров, обычный DOM для меню, PWA-оболочка.
Вся игровая логика берется из `@cupquest/core`. Клиент рисует события ядра и отправляет выбор игрока; правил он не пересчитывает.

Ссылки на разделы ТЗ: CL-, PLT-, TG-, PWA-, UI-, LOC-, ERR-, AUTH-, API- (`ТЗ 5.3`, `ТЗ 6.x`).

## Запуск и сборка

```bash
npm run dev -w packages/client          # Vite на http://localhost:5173; /api проксируется на 127.0.0.1:8787
npm run build -w packages/client        # tsc --strict, затем vite build в dist/
npm run release -w packages/client      # релиз: сначала проверка балансных значений (core, BAL-002), потом build.
                                        # Падает, пока в balance-данных есть значения со статусом open (сейчас 160)
npm run preview -w packages/client      # просмотр собранной версии
npm test -w packages/client             # vitest, файлы в test/
npm run typecheck -w packages/client    # tsc --noEmit
node packages/client/scripts/make-icons.mjs   # пересборка заглушек иконок в public/icons
```

Переменные окружения (`import.meta.env`):

- `VITE_API_BASE` — база API, по умолчанию `/api/v1` (ТЗ 5.3). Для статики на отдельном хосте (ТЗ 3, Cloudflare Pages) задайте
  абсолютный адрес API, например `https://api.example.com/api/v1`, и добавьте origin статики в `CORS_ORIGINS` сервера.
- `VITE_GIT_SHA` — необязательная метка сборки (CI-004).

Для входа и забегов нужен сервер `packages/server` на порту 8787. Без него экраны показывают текст ошибки сети и кнопку «Повторить».

## Telegram

- Официальный скрипт `telegram-web-app.js` подгружается только если в хеше URL есть `tgWebAppVersion=` (запуск Mini App). В браузере скрипт не грузится.
- `window.Telegram?.WebApp` читается один раз при старте. Если объекта нет, игра идет как гость.
- `ready()` и `expand()` вызываются, если методы есть. Ошибки глушатся (ERR-007).
- `requestFullscreen()` вызывается один раз: если метод есть, `isVersionAtLeast('8.0')` истинно, и ошибок нет. Иначе обычный режим (TG-001, PLT-003).
- Вход: при наличии `initData` идет `POST /auth/telegram`; токен живет только в памяти. Иначе гостевой токен хранится в `localStorage` под ключом `cq_device_token`.
- BackButton показывается на всех экранах, кроме главного меню. В забеге он открывает подтверждение выхода (TG-008).
- Вибрация: импульс при падении шара в любые ворота, `success` при x5. При выключенной вибрации вызовов нет (TG-002). В браузере используется `navigator.vibrate`, если есть.

## Экраны

1. Загрузка и вход (`loadingScreen`), экран «Нужна новая версия» при `client.too_old` (ERR-010).
2. Главное меню: балансы, энергия с обратным отсчетом (API-007), играть, таблица, профиль, магазин, настройки. Офлайн-режим: онлайн-кнопки неактивны (ERR-004).
3. Выбор героев: три открытых героя, Друид закрыт и показан с ценой; режим полный или короткий (по флагу сервера), скорость x1 или x2.
4. Бой: Phaser-арена, x1/x2, выход с подтверждением. Диалог воскрешения при гибели героя, если гемы зарезервированы.
5. Выбор карты: три предложения, перебрасывание (5 шаров), улучшение карт, таймер 5 с (по истечении берется первая карта).
6. Поле шаров: путь каждой колонки виден, шансы ворот в панели, перемещение чашки кнопками или перетаскиванием, бросок, таймер 15 с (по истечении бросок в текущую колонку).
7. Конец забега: очки, монеты, шары, ворота, отправка с повторами (ERR-005), награда, таблица недели.
8. Таблица (сегодня и неделя), профиль (балансы, герои, задания, серия входа), магазин (только чтение, оплата отключена), настройки (звук, вибрация, скорость).

## Тесты

Файлы в `test/` (18 файлов, 82 теста; `crash.test.ts` — правило границы ошибок, `cardText.test.ts` — отсутствие id карты в заголовке, `engine.test.ts` — состав побега на шагах карты и поля). ## Допущения

1. Один билд для Telegram и браузера. Среда определяется во время работы; сборки `telegram` и `web` (CL-003) не сделаны. Экран «Откройте игру в Telegram» (PLT-005) не показывается: вне Telegram играет гость.
2. Гость: токен устройства в `localStorage` (`cq_device_token`, исключение PWA-003). Идентификатор установки `cq_install_id` тоже там. Это не результат и не баланс; если токен отвергнут, создается новый гость.
3. Токен Telegram хранится только в памяти вкладки.
4. Настройки (звук, вибрация, скорость) сохраняются в `localStorage`, а не в `CloudStorage` (TG-006 задает CloudStorage). Ключи те же, что в ТЗ.
5. Звук: настройка сохраняется, аудио не подключено (ассетов нет).
6. Таблица: вкладка «Неделя». Вкладка «Сегодня» (`GET /board/daily`) рисуется только при `features.daily_seed = true`; сервер сейчас отдает `false`, API-015 не реализован. Отдельного экрана «Друзья» нет: API отдает пользователя и его друзей.
7. Короткий режим (5 волн) показан, только если серверный флаг `features.short_run` включен.
8. Воскрешение: гемы резервируются при старте (`reserved_gems`), модалка открывается только при резерве. Цена 10 гемов берется из `ECONOMY_VIEW.resurrectGems`.
9. Решение о воскрешении применяется к тику гибели + 1 (CORE-026). Бой заново симулирует ядро с командой `res` (CORE-027); события до решения совпадают, их проверяет `replayWithResurrection`. Если тик + 1 не меньше лимита волны, предложения нет.
10. Таймер выбора карты (5 с) не сбрасывается перебросом. По истечении берется первая карта (`auto_pick`).
11. Таймер броска (15 с): по истечении бросок в текущую колонку (`auto: true`). Стартовая колонка — средняя (индекс 2).
12. Тип ворот каждой колонки скрыт до падения шара; пути и шансы видны (UI-004).
13. Шансы ворот: ядро не экспортирует таблицу, поэтому клиент копирует `total.slot_counts` из `gates.json` (750 000 слотов) и округляет до 0,1 %. Тест сверяет копию с файлом. По этим данным x5 = 20,1 % (в BAL-009 написано 20).
14. Очки = сумма монет и полученных шаров без трат (SEC-003). Считает клиент для показа и отправки; сервер проверяет.
15. Лог забега для `/runs/submit`: `JSON.stringify(state.log)`; ядро не дает сериализатор лога. `log_sha256` — SHA-256 строки в UTF-8.
16. Отправка забега: повторы раз в 5 с до 15 мин (ERR-005) с одним `Idempotency-Key`. Внутри `Api` GET и POST с ключом повторяются 1 с и 3 с (ERR-002). `rate_limited` повторяется один раз через `retry_after`, не больше 60 с (ERR-012).
17. Ошибки ядра (`RuleError`) показываются общим текстом `rule.failed`. Ошибки API идут по коду `err.<код>` (LOC-002).
18. Вибрация: импульс при любом падении шара, `success` при x5. В бою вибрации нет (TG-002 относит ее к полю и бою; здесь выбрано поле).
19. Минимальная версия `requestFullscreen` = 8.0 (значение концепции, [Проверить]). PLT-002 требует подтверждения; до него функция включена при наличии метода и версии 8.0 и выше.
20. Скрипт `telegram-web-app.js` грузится с telegram.org только в Mini App.
21. Иконки — заглушки: темный квадрат и золотой диск (`scripts/make-icons.mjs`). Maskable — то же изображение с меньшим диском.
22. Цвет `--bg` = `#1b1d2a` (PWA-001 требует значения до недели 1, сейчас открыто).
23. Имена героев и врагов взяты из `battle.json` ядра и хранятся в `strings.ru.ts`. Тексты карт не заданы: заголовок «Карта: <герой>» (`card.placeholder`). Id карт в интерфейсе не показываются (LOC-001).
24. Магазин только читает `/config`. Покупки отключены: кнопки «Недоступно». Оплаты Stars в этой итерации нет.
25. Профиль только показывает данные. Повышение уровней, получение заданий и серии не сделаны.
26. Друид закрыт, цена показана (300 гемов или 4 000 монет). Открытие не сделано.
27. Офлайн: онлайн-кнопки неактивны, настройки работают (ERR-004).
28. Перезагрузка во время забега не восстанавливает забег (UI-007).
29. Обновление сервис-воркера: плашка «Доступна новая версия», перезагрузка только по кнопке (PWA-004). Установка: кнопка после первого завершенного забега, не чаще раза в 14 дней (PWA-005).
30. Phaser — отдельный чанк (динамический `import`). Стартовый бандл без Phaser.
31. Preact не используется: по заданию меню на обычном DOM.
32. **Граница ошибок (ERR-006).** `App.crash` при необработанной ошибке (`window` `error` с `ErrorEvent`) или отказе промиса, который не `ApiError`
    (`isRenderCrash`), сбрасывает забег, возвращает в меню и показывает `err.run_crashed`. Ошибку получает `reportCrash`; по умолчанию это консоль.
    Отправки в Sentry нет: в репозитории нет DSN и SDK. Сервер закроет такой забег как `timeout` через 30 мин.
33. **Отклоненный забег.** `flagged` показывает `err.run_flagged` (SEC-006). Награды не начисляются, энергия не возвращается.
34. **Ошибки забега.** `run.active` и `run.timeout` имеют тексты (`err.run.active`, `err.run.timeout`). Без них клиент показывал общий текст сервера.
35. **Отправка после побега.** Побег на шагах выбора карты и поля отправляет текущую волну с монетами и без ворот (`waves` = `last_wave`). Сервер принимает это по правилу SEC-001, зафиксированному в его README.

## Не сделано (следующая итерация)

- Оплата Stars и выключатель продаж в UI (сервер отдает `payments_enabled=false`).
- Друзья, рефералы, Telegram Login и связка `/link` для браузера.
- Шаринг карточки (prepared message, `shareMessage`, Web Share).
- Режим «сид дня» (`daily`) и дневная доска (API-015): сервер не отдает доску дня, флаг `daily_seed` выключен.
- Sentry: отправка ошибок (ERR-011) не подключена, нужны DSN и SDK.
- Сборки `telegram` и `web` по `TARGET`, экран PLT-005, CloudStorage.
- Тексты карт и значения, которые в ядре помечены как открытые.
- E2E через Playwright, сверка с golden-векторами в браузере.
- Звук и графика вместо заглушек.
